# ゲームタイトル
4目並べ

## ゲームの概要
縦6マス×横7列の盤面で、2人のプレイヤーが交互に石を落として遊ぶコンソールゲームです。縦・横・斜めのいずれかに自分のマークを4つ以上並べると勝利です。

- プレイヤー1：`X`（先手）
- プレイヤー2：`O`
- 盤面がすべて埋まり、勝敗が決まらない場合は引き分けです。

## 動作環境
- OS：Windows / Linux
- Python：Python 3
- 必要なライブラリ：追加ライブラリ不要（Python標準ライブラリの `sys` と `time` を使用）

## インストール方法
標準ライブラリのみで動作するため、追加パッケージのインストールは不要です。  
ソースコード（`w144moku.py`）を任意のフォルダにダウンロード・配置してください。

## 起動方法
ターミナルまたはコマンドプロンプトで、`w144moku.py` があるフォルダーに移動して次のコマンドを実行します。

```bash
python w144moku.py
```

環境によっては `python3 w144moku.py` で起動できます。

## 操作方法
- `1`〜`7` を入力してEnter：石を落とす列を選択
- `R` を入力してEnter：ゲームを最初からやり直す（手番もXに戻ります）
- `Q` を入力してEnter：ゲームを終了

石は選んだ列の上から落ち、最も下の空いているマスに置かれます。すでにいっぱいの列を選んだ場合は、別の列を選び直してください。勝敗が決まった後は、`R` で再戦、`Q` で終了できます。

## 追加・改良した機能

### 改良機能01：（機能名）

### 改良機能02：（機能名）
ゲーム中に `R` を入力すると盤面を初期状態に戻して再スタートできます。勝敗が決まった後も再戦できます。

### 改良機能03：（機能名）
縦・横・斜めの4目判定、引き分け判定、いっぱいの列への入力チェックに対応しています。
